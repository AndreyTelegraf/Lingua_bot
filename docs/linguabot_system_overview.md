# LinguaBot v2 — System Overview

## What this project is

LinguaBot v2 is a multi-stage language learning and assessment system for Portuguese.

It is not just a vocabulary tool.

It is a structured user progression pipeline consisting of multiple independent but connected blocks.

## Core principle

The system is built around a progression model:

diagnostic → calibration → guided learning → exam readiness

Each block produces signals that feed the next one.

## Main blocks

1. Vocab (lexical diagnostic)
2. Level (CEFR competence)
3. CIPLE (A2 exam simulation)

## Critical constraint

Vocab is NOT a general-purpose word list.

It is a diagnostic measurement instrument.

Errors in vocab propagate downstream.
